# Roadmap

## What this is
A study task list for people learning a language. You sign in, add study tasks tagged with the skill they practice, and the site shows which skill you have been avoiding.

## What Done means
A stranger can open the live site, create an account with an email and password, and sign in. They can add a study task and tag it with one of six skills: Reading, Writing, Listening, Speaking, Vocabulary, or Grammar. They can mark a task done. When they sign out and sign back in, their tasks are still there, and nobody else's tasks are visible. A summary on the task page counts the tasks they completed in each skill over the last 7 days and labels the skill with the lowest count "Avoiding"; if several skills tie for lowest, all of them get the label. Nothing more is needed for a stranger to use it once.

## Slices
1. Sign up and log in | done-criteria: (a) On the live site, go to the sign-up page, enter a new email and a password, submit, click the link in the confirmation email, and land on the site showing "Signed in as" followed by that email; (b) Click "Sign out" and see a "Log in" link where the email was; (c) On the log-in page, enter that email with a wrong password and see an error message while staying on the log-in page; (d) Log in with the right password, close the tab, open the live site in a new tab, and still see "Signed in as" with that email | status: ACTIVE
2. Tasks that stay | done-criteria: (a) While signed in, type "Read one news article" into the add box, press Add, and see it appear in the list; (b) Reload the page and see the same task still in the list; (c) Click the task's Done checkbox, reload, and see it still marked done; (d) Sign out, sign in as a second account, and see none of the first account's tasks | status: pending
3. Skill tags and the avoided skill | done-criteria: (a) Try to add a task without picking a skill and see a message asking for a skill, with no task added; (b) Add a task with the skill Listening and see "Listening" shown on that task in the list; (c) Mark one task done in each of five skills, none in Speaking, and see the summary show a count for all six skills with "Avoiding" next to Speaking only; (d) Mark a Speaking task done, reload, and see the Speaking count go from 0 to 1 | status: pending

## Backlog
- Editing a task's text
- Deleting tasks
- Due dates and reminders
- Password reset ("forgot password")
- Sign in with Google or other providers
- Custom skills beyond the six
- Tracking more than one language
- Streaks, charts, or history longer than 7 days
- Sorting and filtering the list
- Deleting an account
- Mobile app
- Sharing lists with a teacher or study partner
